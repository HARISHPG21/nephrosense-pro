## 📌 About
NephroSense Pro predicts Chronic Kidney Disease risk using 
machine learning trained on the UCI CKD Dataset (400 patients, 
25 clinical features). Achieves 98.8% ensemble accuracy.

## ✨ Features
- CKD Risk Prediction (25 clinical parameters)
- eGFR calculation using CKD-EPI formula
- KDIGO staging G1–G5
- Batch CSV processing (up to 100 patients)
- Interactive Risk Calculator with live gauge
- ML Model comparison (9 algorithms)
- SHAP feature importance visualization
- ROC curve display
- Download / Print / Copy report
- Dark & Light theme
- Fully responsive

## 🧠 ML Models
| Model | Accuracy | AUC-ROC |
|-------|----------|---------|
| Ensemble | 98.8% | 0.993 |
| Random Forest | 98.5% | 0.991 |
| XGBoost | 97.8% | 0.989 |
| SVM | 96.3% | 0.981 |

## 📊 Dataset
- Source: UCI Machine Learning Repository
- Records: 400 patients (250 CKD, 150 non-CKD)
- Features: 25 clinical attributes
- Link: https://archive.ics.uci.edu/ml/datasets/Chronic_Kidney_Disease
